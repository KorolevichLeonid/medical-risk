# Risk Management Document Generation - User Guide

## Обзор

Система автоматической генерации документов Risk Management Report для проектов медицинских изделий.

## Основные возможности

✅ **Автоматическая генерация** документов в формате DOCX  
✅ **История версий** с отслеживанием изменений  
✅ **Просмотр** всех версий документов  
✅ **Скачивание** любой версии документа  
✅ **Автоматическое заполнение** данных из базы данных проекта  

---

## Как использовать

### 1. Генерация документа

1. Откройте страницу проекта (`/project/{id}`)
2. Нажмите кнопку **"📄 View Document"**
3. На странице документов нажмите **"🔄 Generate New Version"**
4. Подтвердите генерацию
5. Документ будет создан автоматически с новым номером версии

**Автоматическая нумерация версий:**
- Первый документ: `v1.0`
- Последующие версии: `v1.1`, `v1.2`, ..., `v2.0`

### 2. Просмотр документа

На странице документов вы увидите:
- **Информацию о текущей версии** (версия, номер отчета, размер файла)
- **Структуру документа** (список всех разделов)
- **Дату и автора** генерации

### 3. Скачивание документа

1. На странице документов нажмите **"⬇️ Download Document (DOCX)"**
2. Файл будет сохранен на ваш компьютер
3. Откройте в Microsoft Word или любом редакторе DOCX

### 4. История версий

1. Нажмите **"📋 Version History"** для просмотра всех версий
2. Выберите любую версию из списка для просмотра
3. Скачайте конкретную версию кнопкой ⬇️ рядом с версией

## Структура документа

Сгенерированный документ содержит следующие разделы:

### 1. ТИТУЛЬНЫЙ ЛИСТ
- Название медицинского изделия
- Модель и производитель
- Номер отчета и версия
- Подписи команды

### 2. СОДЕРЖАНИЕ
- Список всех разделов документа

### 3. ИДЕНТИФИКАЦИЯ ИЗДЕЛИЯ И НАЗНАЧЕНИЕ
- Информация об изделии
- Классификация и назначение
- Этапы жизненного цикла
- Категории опасностей

### 4. ИДЕНТИФИКАЦИЯ ОПАСНОСТЕЙ
- Чек-лист вопросов
- Таблица идентифицированных опасностей
- Резюме раздела

### 5. АНАЛИЗ РИСКОВ (до мер контроля)
- Методология оценки (матрица 5×5)
- Шкалы тяжести и вероятности
- Таблица анализа рисков
- Критерии приемлемости

### 6. МЕРЫ УПРАВЛЕНИЯ РИСКАМИ
- Таблица мер контроля
- Методы верификации

### 7. ОЦЕНКА ОСТАТОЧНЫХ РИСКОВ
- Таблица остаточных рисков после мер контроля
- Оценка приемлемости

### 8. ОЦЕНКА СОВОКУПНОГО ОСТАТОЧНОГО РИСКА
- Общий остаточный риск
- Соотношение польза/риск

### 9. ВЫВОДЫ И УТВЕРЖДЕНИЕ
- Общие выводы
- Заключение
- Таблица подписей команды

### 10. ССЫЛКИ И УПРАВЛЕНИЕ ДОКУМЕНТОМ
- Нормативные документы
- Метаданные документа

### ПРИЛОЖЕНИЕ А
- Полная таблица управления рисками

## Источники данных

Документ автоматически заполняется данными из:

### Таблица `projects`
- Название устройства
- Модель и классификация
- Назначение и среда эксплуатации
- Этапы жизненного цикла
- Активные категории опасностей

### Таблица `risk_table_rows`
- Все идентифицированные риски
- Опасные ситуации и последовательности событий
- Оценки тяжести и вероятности
- Меры контроля
- Остаточные риски

### Таблица `project_members`
- Состав команды проекта
- Роли участников

**Подробный маппинг данных см. в файле `DOCUMENT_DATA_MAPPING.md`**

---

## Поля-заглушки (PLACEHOLDER)

⚠️ **Некоторые поля помечены как PLACEHOLDER:**

Это означает, что данные еще не реализованы в базе данных или требуют доработки:

- **Manufacturer** (производитель) - нужно добавить в таблицу projects
- **Manufacturer Address** - нужно добавить в таблицу projects
- **Patient Population** - нужно добавить в таблицу projects
- **Checklist Answers** - требует рендеринга JSON данных
- **Team Signatures** - требует назначения ролей (Prepared by, Reviewed by, Approved by)
- **Overall Risk Formula** - требует конфигурации формулы расчета

**Эти поля можно заполнить вручную в Word после скачивания документа.**

## Рекомендации по подготовке данных

Для наилучшего качества документа убедитесь, что заполнены:

### ✅ В проекте:
- Название и модель устройства
- Классификация риска
- Назначение и среда использования
- Этапы жизненного цикла
- Стандарты и регуляции

### ✅ В таблице рисков:
- Lifecycle Stage (этап жизненного цикла)
- Hazard (опасность)
- Hazardous Situation (опасная ситуация)
- Sequence of Events (последовательность событий)
- Harm (вред)
- Severity Initial (начальная тяжесть, 1-5)
- Probability Initial (начальная вероятность, 1-5)
- Control Measures (меры контроля)
- Severity Residual (остаточная тяжесть, 1-5)
- Probability Residual (остаточная вероятность, 1-5)

## API Endpoints

### Генерация документа
```
POST /api/documents/projects/{project_id}/generate
```

### Получить текущий документ
```
GET /api/documents/projects/{project_id}/current
```

### История версий
```
GET /api/documents/projects/{project_id}/versions
```

### Скачать версию
```
GET /api/documents/projects/{project_id}/versions/{version_id}/download
```

## Устранение проблем

### Документ не генерируется
- Проверьте, что в проекте заполнены обязательные поля
- Проверьте, что есть хотя бы один риск в таблице рисков
- Проверьте логи backend на наличие ошибок

### Не отображаются данные в документе
- Убедитесь, что данные в БД заполнены корректно
- Проверьте формат JSON полей (lifecycle_stages, active_hazard_categories)
- См. `DOCUMENT_DATA_MAPPING.md` для деталей

### Ошибка при скачивании
- Проверьте размер документа (должен быть > 0)
- Проверьте права доступа к проекту
- Очистите кэш браузера
