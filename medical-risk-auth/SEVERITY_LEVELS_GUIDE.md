# Руководство по настройке уровней тяжести последствий

## 📋 Обзор

Система теперь поддерживает настраиваемые уровни тяжести последствий для каждого проекта. Это позволяет гибко адаптировать оценку рисков под специфику конкретного медицинского устройства.

## ✨ Основные возможности

### 1. Настраиваемые уровни тяжести

- **Минимум:** 2 уровня
- **Максимум:** неограниченно
- **Автоматическая нумерация:** Уровни нумеруются последовательно (1, 2, 3, ...)
- **Балл = Уровень:** Столбец "Балл" убран, так как балл автоматически равен номеру уровня

#### По умолчанию предлагается 5 уровней:

| Уровень | Название | Описание |
|---------|----------|----------|
| 1 | Незначительный | Приводит к неудобству или временному дискомфорту |
| 2 | Незначительный/Легкий | Приводит к временному повреждению или нарушению, не требующему медицинского вмешательства |
| 3 | Серьезный/Значительный | Приводит к повреждению или нарушению, требующему медицинского или хирургического вмешательства |
| 4 | Критический | Приводит к постоянному нарушению или необратимому повреждению |
| 5 | Катастрофический/Фатальный | Приводит к смерти |

### 2. Динамическое пороговое значение риска

- **Формула расчета максимального риска:** `(максимальный уровень)²`
- **Пример:** Если у вас 7 уровней, максимальный риск = 7² = 49
- **Диапазон:** от 1 до максимального риска

#### Как это работает:

```
Риск = Тяжесть вреда × Вероятность причинения вреда

Если Риск >= Пороговое значение → Риск "Недопустимый" ❌
Если Риск < Пороговое значение  → Риск "Допустимый" ✓
```

## 🎯 Как использовать

### Создание нового проекта

1. Откройте форму создания проекта
2. Заполните основную информацию и этапы жизненного цикла
3. В секции **"Уровни тяжести последствий"**:
   - Отредактируйте существующие уровни (название и описание)
   - Добавьте новые уровни кнопкой **"+ Добавить уровень"**
   - Удалите ненужные уровни (минимум 2 должны остаться)

4. В секции **"Уровень риска (доп./не доп.)"**:
   - Укажите пороговое значение
   - Система автоматически вычислит допустимый диапазон

5. Сохраните проект

### Редактирование существующего проекта

1. Откройте проект для редактирования
2. Измените уровни тяжести или пороговое значение
3. Сохраните изменения

**⚠️ Важно:** Изменение уровней тяжести в существующем проекте с уже созданными рисками может потребовать пересмотра оценок.

### Оценка рисков

При оценке рисков в таблице управления рисками:

1. **Ограничение баллов:**
   - Нельзя выставить оценку тяжести или вероятности больше максимального уровня
   - Например, если максимальный уровень = 7, то нельзя поставить 8

2. **Автоматическое определение допустимости:**
   - После заполнения оценок система автоматически определяет допустимость риска
   - Ячейки подсвечиваются:
     - 🟢 **Зеленый** = Допустимый риск
     - 🔴 **Красный** = Недопустимый риск

## 🔧 Технические детали

### Структура данных

#### Severity Levels (JSON)
```json
[
  {
    "level": 1,
    "name": "Незначительный",
    "description": "Приводит к неудобству или временному дискомфорту"
  },
  {
    "level": 2,
    "name": "Незначительный/Легкий",
    "description": "Приводит к временному повреждению..."
  }
]
```

#### Risk Threshold (Integer)
```json
{
  "risk_threshold": 10
}
```

### API Endpoints

#### Создание проекта
```http
POST /api/projects/
Content-Type: application/json

{
  "name": "Test Project",
  "device_name": "Test Device",
  "severity_levels": [...],
  "risk_threshold": 10,
  ...
}
```

#### Обновление проекта
```http
PUT /api/projects/{project_id}
Content-Type: application/json

{
  "severity_levels": [...],
  "risk_threshold": 15
}
```

### База данных

**Таблица:** `projects`

| Колонка | Тип | Описание |
|---------|-----|----------|
| `severity_levels` | TEXT | JSON массив с уровнями тяжести |
| `risk_threshold` | INTEGER | Пороговое значение риска (по умолчанию: 10) |

## ❓ FAQ

**Q: Можно ли изменить уровни после создания проекта?**
A: Да, но будьте осторожны - это может повлиять на существующие оценки рисков.

**Q: Что произойдет, если я уменьшу количество уровней?**
A: Система автоматически пересчитает максимальное значение риска и скорректирует пороговое значение, если оно стало больше нового максимума.

**Q: Можно ли иметь разные уровни для разных проектов?**
A: Да! Каждый проект имеет свои собственные настройки уровней тяжести.

**Q: Что если я хочу вернуться к стандартным 5 уровням?**
A: При создании проекта всегда предлагаются стандартные 5 уровней. Вы можете вручную удалить/добавить уровни или скопировать структуру из другого проекта.
